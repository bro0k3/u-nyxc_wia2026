Judul Project: WEBSITE FIREWATCH
Deskripsi: Website yang dipergunakan untuk melihat progres upaya penanganan kebakaran hutan terkhusus di Indonesia, menampilkan kas terbuka, dan menampung aspirasi juga laporan dari rakyat terkait dengan kebakaran hutan.
Tech Stack: - Frontend: HTML, CSS(tailwind), Javascript.
            - Backend: Python, Flask, SQLite
Cara Menjalankan: clone --> fetch --> run app.py --> buka web dengan copy paste port
